# How to Install

## Prerequisites
- Anaconda Python

## Installation Steps
- Create the virtual environment: **conda create --name Admin python=3.6.13**
- Activate the virtual environment: **conda activate Admin**
- Install all dependencies listed in the ./requirements.txt file: **pip install -r requirements.txt**
